# План реализации универсального окна Neuralese

## Цель

Сделать одну переиспользуемую Godot-сцену для окон с настраиваемым заголовком, Markdown-текстом, размером, штатной иконкой и набором кнопок. Первое реальное применение — предложение скачать новую версию Neuralese. Дизайн и анимации берутся из существующего интерфейса проекта.

## Ограничения

- Работа ведется в отдельной ветке `codex/multipurpose-dialog` от актуального `origin/main`.
- Новые изображения, шрифты, шейдеры и отдельная дизайн-система не создаются.
- Существующие окна login, signup, project create и Axon пока не мигрируют.
- Backend и формат старого ответа `/check` не ломаются.
- Обновление не скачивается без явного нажатия пользователя.
- Ветка не пушится без отдельного разрешения.

## Ожидаемый результат

Любой код Neuralese сможет передать JSON-совместимый `Dictionary` и получить готовое окно в текущем стиле приложения без создания новой `.tscn` под каждый кейс. Механизм обновлений станет первым потребителем: он сравнит версии, покажет понятное предложение и начнет действие только после выбора пользователя.

# Проверка частичного сжатия clean1000

Исследовательский эксперимент, не изменение production runtime. Исходный kit и
подготовленная модель Neuralese остаются неизменными; производные веса хранятся
в отдельном каталоге cache.

1. Зафиксировать английские calibration / validation / test выборки из kit,
   формат ChatML и детерминированные проверки ответов. Сравнивать качество
   выполнения задач, assistant-only NLL и согласие с исходной моделью раздельно.
2. Проверить физическое удаление 1–2 блоков с повторной оценкой после удаления
   (SLEB), сокращение MLP 1024 → 896/768/512, компенсацию среднего и ridge refit
   оставшейся down projection. Проверить простое слияние как контроль.
3. Экспортировать перспективные варианты в ONNX, проверить cached decoding и
   целостность исходных файлов. Отдельно проверить удаление дублированной tied
   матрицы, INT8 и INT4. Замерять размер и скорость фиксированной работы, не
   путать меньший файл с меньшим числом слоёв или ускорением.

Решение выбирать по validation, финальный test не использовать при подборе.
Обязательные ограничения отчёта: небольшой benchmark; пределы grader; pruning
не обязан сохранять качество; параметры пользовательского графа пока не
подключены к полученным экспериментальным профилям.

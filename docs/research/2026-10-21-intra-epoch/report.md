# Промежуточная визуализация долгих эпох

Порог пользователя: первая эпоха **строго >0,3 с**. Подготовка модели исключена. Числовой worker сообщает фактическое прошедшее время batch/epoch; языковой — сумму времени существующих training_step внутри эпохи. Задержка доставки событий в Godot не определяет классификацию. При переходе порога поток включается со следующего доступного запроса; после первой эпохи классификация фиксируется до нового запуска обучения.

Существующие batch snapshots сохранены. Уже вычисленный prompt preview теперь может прийти раньше последующей оценки метрик. Нет дополнительных forward, eval или экспорта ONNX. Producer и применение UI ограничены 4 Гц; optional preview ≤64 КиБ, только подписанные видимые ноды, без полной vocabulary. Транспорт читает короткий заголовок раз в 50 мс только при активной подписке, хранит последний пакет отдельно для каждой сессии. Terminal response остаётся обязательным и имеет приоритет. Для одного атомарного вычисления есть лёгкий индикатор активности: он не подменяет метрики или реальные attention.

## Измерения

Apple M5, Python 3.11.15, ONNX Runtime 1.19.2, Godot 4.7.1. Исходный clean1000 не изменён. Английский ввод `Copy exactly: red cup`, одинаковый граф, dataset, seed. Один прогрев + 5 повторов по 3 эпохи, 12 batch/эпоху. Варианты запускались последовательно, без параллельных тестов.

| Сценарий | Без потока | С потоком | Изменение |
|---|---:|---:|---:|
| Godot: медиана отдельной эпохи | 2,139541 с | 2,148073 с | +0,40% |
| Godot: p95 отдельной эпохи | 2,169339 с | 2,258416 с | +4,11% |
| Godot: учтённое CPU-время дочернего процесса за весь сценарий | 61,889 с | 62,426 с | +0,87% |
| Godot: peak RSS | 823443456 байт | 716079104 байт | отдельные процессы; не оценка потребления GPU |
| Worker: медиана эпохи, текущий код | 1,245500 с | 1,245923 с | +0,034% |
| Worker: p95 эпохи, текущий код | 1,327302 с | 1,470239 с | +10,77% |
| Worker: медиана CPU/эпоху | 2,245706 с | 2,233670 с | −0,54%, вариативность измерений |
| Worker: forward/эпоху | 108 | 108 | 0 |

Godot baseline — commit `c7bc3b7`, тестовая сцена одинакова. Каждая эпоха измерена от отправки первого batch до получения terminal response последнего batch, без prepare_model; последнее применение UI и GPU-показ кадра в эту границу не входят. CPU — `RUSAGE_CHILDREN` вокруг полного запуска Godot, включая прогрев/запуск, а не CPU отдельной эпохи. Worker сравнен также с исходным c7bc3b7: медиана 1,236620 с →1,245923 с (+0,75%). JSON сохраняет все отсчёты.

Накладные расходы по медиане ниже целевого 1%, **по p95 гарантия <1% не подтверждена**. Выборка мала (15 эпох), варианты не перемежались, хвосты включают шум ОС; положительный p95 нельзя выдавать за отсутствие замедления. Снижение частоты не доказано способом устранить этот хвост: пакеты редки, новых вычислений нет. Для строгого SLA нужны более длительные перемежающиеся прогоны на целевом Windows-компьютере.

В Godot получено и реально применено 97/97 ранних preview (включая прогрев). По 36 training_step за каждый запуск в обоих вариантах; финальные raw accuracy/loss совпали точно. Worker опубликовал 56 пакетов на 15 измеренных эпох, всего 1544795 байт, максимум 27666 байт/пакет. Отключённый поток — 0 пакетов/байт. Полные финальные ответы сохраняются для совместимости.

## Проверки и пределы

- 214 Python-тестов: runtime, реальные preview, per-session mailbox, публикация до corpus metrics, равенство forward count, numeric batch elapsed, export/staging, каталог нод.
- Godot: порог 300000/300001 мкс, независимость от задержки UI, fast classification, 4 Гц, активность атомарного вызова без изменения accuracy, отдельный прогресс эпохи, cancel/restart, stale session/revision/text, реальные attention/embeddings.
- Полный Godot-прогон: 100 PASS, 7 существующих ошибок, совпадающих с исходной веткой (remote_transport_guards, remote_action_behavior, local_training_worker, project_gallery, builtin_projects_blur_release, settings_quality_carousel, simulation_tab). После финальных исправлений отдельно повторены затронутые тесты.
- Это headless CPU/UI проверка. Видимый GPU UI и видео остаются непроверенными: Mac заблокирован. Стоимость числового ONNX Training на macOS не измерялась, его batch-источник переиспользован без дополнительных вычислений модели.

Воспроизведение: `tools/language_models/benchmark_epoch_preview.py` (с/без `--preview`) и `benchmark_epoch_preview_ui.py` (контрольный `--baseline-ref c7bc3b7`). UI helper временно заменяет только изменённые исходники продукта и восстанавливает точные байты в finally; нельзя параллельно редактировать/тестировать эти файлы.

Windows export commit `90ef7a3`: [изолированный CI PASS](https://github.com/Neuralese-LLP/neuralese-builder/actions/runs/39596075095). Штатный release-export, перенесённый EXE с тестовой стартовой сценой, исходный runtime удалён, пустой профиль, PATH без внешнего Python, OS firewall блокирует встроенный Python и EXE (ошибка сети 10013). Реальные attention, word embeddings, `red cup`, learning previews прошли. Это headless backend-проверка; полный установщик и видимый интерфейс не входят в её охват. Лог и ограничения: [windows-offline.json](windows-offline.json).

# Штатный local runtime для языковых моделей

Отдельные language worker/mailbox и Godot-цикл эпох удалены. Инференс проходит через RunManager, его LocalInferChannel и общий infer_loop.py. Обучение проходит через обычные PreparedSession → START/STOP resident worker либо существующий train_entry.py fallback. PreparedLanguageSession — реализация модели внутри runtime, не новый transport.

Runtime владеет восстановлением модели, эпохами, порогом >0,3с по первой эпохе, частотой preview, фиксированным набором validation и отображаемым accuracy ×4. Godot использует обычные state/left/done/stopped/error; отдельной логики симуляции обучения в TrainBegin нет. Ноды и авторегрессия сохранены.

Разбор inference JSON выполняется в фоновом Thread; ответ атомарно захватывается до чтения, чтобы ready не мог удалить следующий результат. Для UI передаются 20 реальных кандидатов с исходными ID/вероятностями вместо сортировки20 002 значений в GDScript. Используется общий профиль ONNX SessionOptions без spinning. Убраны полоска и бегущий маркер активности.

Циклическая смена validation-поднабора и повторная многократная оценка корпуса на каждом batch удалены. Сравнивается один фиксированный набор в конце каждой эпохи. Это по-прежнему восстановление предобученной модели, а не SGD; управление находится в runtime.

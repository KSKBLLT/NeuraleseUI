# План стартового тура Neuralese

## Результат

После тура ученик или учитель должен понимать четыре вещи:

1. Neuralese собирает ИИ-модели из нодов.
2. Где открыть проект, симуляцию, граф и датасет.
3. Как добавить две ноды и соединить их в короткую цепочку.
4. Где попросить помощь у Axon.

Тур запускается после первого заполнения профиля. Его можно пропустить в любой момент зелёной кнопкой. Полоса прогресса в стартовом туре скрыта, чтобы не перекрывать верхнюю панель. Повторный запуск доступен из встроенных уроков.

## Сценарий

| Шаг | Что видит пользователь | Что он должен понять |
| --- | --- | --- |
| 1. Приветствие | Короткое объяснение без стрелки | Neuralese позволяет собирать ИИ из блоков, как в Scratch |
| 2. Верхняя панель | Объяснение панели и папки | Папка открывает главное меню, пустое место закрывает его |
| 3. Главное меню | Толстая стрелка и подсветка папки | Пользователь сам открывает меню и закрывает его |
| 4. Главные вкладки | Короткое объяснение без стрелки | В центре находятся Симуляции, Графы и Датасеты |
| 5. Открытие Симуляций | Стрелка и подсветка вкладки | Пользователь сам открывает Симуляции |
| 6. Симуляции | Короткое объяснение | Здесь проверяется поведение нейросети |
| 7. Открытие Датасетов | Стрелка и подсветка вкладки | Пользователь сам открывает Датасеты |
| 8. Датасеты | Короткое объяснение | Здесь собираются примеры для обучения |
| 9. Открытие Графов | Стрелка и подсветка вкладки | Пользователь сам открывает Графы |
| 10. Графы | Короткое объяснение | Здесь собираются нейросети |
| 11. Первая нода | Стрелка и подсветка палитры | Пользователь добавляет `Input1D` |
| 12. Вторая нода | Простая инструкция | Пользователь добавляет `Dense` справа от первой ноды |
| 13. Соединение | Простая инструкция и конфетти | Пользователь соединяет две ноды |
| 14. Axon | Стрелка и подсветка Axon | Помощника можно спросить обычными словами |
| 15. Завершение | Короткое итоговое сообщение | Пользователь готов самостоятельно исследовать Neuralese |

## Правила текста

- Один экран объясняет только одну мысль.
- Не использовать термины до их короткого объяснения.
- Не требовать действия, которое пользователь ещё не видел.
- Основной текст должен помещаться без внутренней прокрутки при разрешении 1280×720.
- Русская, английская и казахская версии должны передавать одинаковый смысл, а не быть дословным машинным переводом.

## UI

- Обычные уроки сохраняют прежнюю стрелку: толщина 6 px, наконечник 20 px, без тени.
- Стартовый тур через `tutorial_ui.arrow_style` включает толщину 11 px, наконечник 30 px и тень.
- Стрелка направлена в центр стороны целевого элемента и продолжает следовать за ним.
- `tutorial_ui.highlight_style` задаёт прозрачность центра и отступ радиальной подсветки.
- Подсветка рисуется на отдельном верхнем `CanvasLayer` через additive blending и не перехватывает ввод.
- Предыдущая стрелка исчезает до появления следующей.
- Предыдущая подсветка исчезает до появления следующей.
- Кнопка пропуска всегда доступна, локализована и окрашена зелёным акцентом Neuralese.
- Стартовый тур задаёт `tutorial_ui.show_progress: false`; обычные уроки по умолчанию сохраняют прогресс-бар.

## Проверка

- Тур компилируется из YAML и содержит пятнадцать шагов.
- Все указанные UI-цели существуют в сценах.
- Перед каждым `wait_ui` целевой элемент получает стрелку и подсветку.
- Обычный урок без `tutorial_ui.arrow_style` использует прежние параметры стрелки.
- Подсветка имеет радиальную текстуру, белый прозрачный край и additive-материал.
- Пропуск останавливает урок, очищает стрелки и больше не запускает тур автоматически.
- Завершение помечает тур пройденным.
- На Windows и macOS кнопка пропуска реагирует на обычный mouse release.
- После закрытия главного меню левая панель нодов возвращается в прежнее состояние.
